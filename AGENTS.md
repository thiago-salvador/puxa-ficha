# Instruções do projeto

Antes de planejar, editar código, atualizar dados ou operar ambientes, leia
[Settings/README.md](Settings/README.md) e siga a ordem indicada ali.

O objetivo permanente é cobertura pública completa de todos os candidatos à
Presidência e aos governos estaduais em 2026. Uma mudança de dados só termina
quando aparece corretamente na ficha pública.

Toda task deve demonstrar como aproxima o projeto da base mais completa e
confiável possível sobre cada candidato. Se essa contribuição não puder ser
explicada e verificada, a task não deve ser executada nem considerada progresso.

Regras globais do ambiente continuam válidas. Em conflito, use a hierarquia de
autoridade definida em `Settings/README.md` e preserve segurança, identidade,
proveniência e aprovação editorial.
